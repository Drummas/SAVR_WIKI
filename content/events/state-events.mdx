## Why state events punish improvisation

A state event asks an entire server (or several servers) to push one objective at the same time. Individual players can score well by accident. Alliances only win with a plan.

The framework here applies to any state-level objective:

- **One coordinator** owns the target list and the final push.
- **Squad leads** own execution in their time zone.
- **Members** get a clear ceiling and a clear role.
- **An archivist** captures the rules and result before the screen disappears.

## Objective types you may encounter

| Objective pattern | What it rewards | Coordination requirement |
| --- | --- | --- |
| Territory / map control | Holding or capturing locations | Rally timing and defence rotation |
| Quest / task scoring | Completing event-specific tasks | Task allocation across the roster |
| Combat score | Defeats, kills, damage | Target calling and rally discipline |
| Resource contribution | Gathering, donating, stockpiling | Logistics and protection |
| Hybrid | Multiple score sources | Central scoreboard and explicit priorities |

<Callout type="info" title="Do not import rules from another event">
Kingdom Clash, Alliance Duel, Elixir Scramble and Survival Battle have different score sources. The label "state event" is not a rule set.
</Callout>

## The 12-hour cadence

State events are long enough for momentum to stall. Use a simple cadence:

- **T+0:** rules captured, roles assigned.
- **T+12h:** first status update, adjust the target.
- **T+24h:** contribution check, release a small reserve if needed.
- **Final 2h:** coordinator calls the closer push.
- **T+24h after close:** after-action note and screenshots archived.

This rhythm keeps the event visible without turning it into a second job.

## Contribution without whale pressure

Not every member can top a damage board. Build contribution paths that respect account size:

- Scouting and map intelligence.
- Reinforcing rally leads.
- Resource logistics and donation.
- Defence shifts while stronger members attack.
- Documentation and score tracking.

Publish effort alongside raw score. An alliance that only celebrates the biggest spender will lose its mid-tier members — and those members are the depth that wins longer events.
