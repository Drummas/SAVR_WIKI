<Callout type="strategy" title="Reserve-first budgeting">
**Event budget = stockpile − reserve floor.** If that number is small, your event spend is small. This one rule prevents most post-event resource crashes.
</Callout>

## The three-bucket model

Every resource sits in one of three buckets:

| Bucket | Purpose | Spending rule |
| --- | --- | --- |
| Reserve | AvA, defence, emergency | Never spent on optional events |
| Pipeline | Queues and production | Replenished continuously |
| Budget | Current event excess | Spend inside the scored window |

If you cannot tell which bucket a resource is in, it is not budget.

## Production uptime

Resources only appear when production runs. Check:

- Are all production buildings staffed and active?
- Is storage capacity at least one login interval above production?
- Are gather teams on the right node type?
- Is anything capped right now?

Fixing uptime usually beats a temporary gather boost. It is free, repeatable and compounds.

## Storage and the overflow trap

A large stockpile feels safe until it caps. Overnight overflow is invisible waste. Two habits fix it:

1. Upgrade storage before a long offline period.
2. Spend the overflow on a useful queue, not on a random upgrade.

<Callout type="warning" title="Do not confuse stockpile with progress">
A big bank that blocks storage is not an achievement. It is an unspent production bonus. Convert it into queue uptime or a planned scored action.
</Callout>

## Event spending order

When a scored window opens, spend in this order:

1. **Free actions** — natural regeneration, existing queues, alliance help.
2. **Cheap threshold actions** — smallest spend that clears the next tier.
3. **Planned reserve release** — only on the coordinator's call.
4. **Never** the AvA floor.

## Weekly review

Every week, answer three questions:

- Did production ever cap? Why?
- Did any event spend breach the reserve floor?
- Which reward converted into the most queue uptime?

Write the answers next to your plan. Resource management improves through feedback, not willpower.
