<Callout type="strategy" title="The five-step loop">
**Verify → Map → Stage → Spend → Log.** Skip a step and the plan becomes a guess. Repeat the loop weekly and the alliance builds a real conversion dataset.
</Callout>

## 1. Verify

Open every live event tab. Capture:

- Phase/theme order.
- End time in UTC and local time.
- Scored actions.
- Reward preview.
- Eligibility.

Community schedules are leads, not evidence. If the live screen contradicts a guide, the live screen wins.

## 2. Map

Put every active event on one weekly grid. Mark:

- **Hard windows** — fixed start/end times.
- **Soft windows** — phases that last a day.
- **Intersections** — actions that score twice.
- **Dead zones** — times with no valuable scoring.

<Callout type="info" title="One map, not five plans">
Separate plans create conflicts. A single map shows which stockpile is wanted by two events at the same time — the most important thing to know.
</Callout>

## 3. Stage

Most high-value actions take hours. Stage them:

- Start long timers early enough to finish inside the window.
- Keep a cheap filler action for queue gaps.
- Hold instant-finish items and speed-ups for the final adjustment.
- Screenshot the timer so the next stage is factual.

## 4. Spend

Use the hierarchy:

1. Free actions.
2. Cheapest threshold-clearing action.
3. Planned overlap spend.
4. Closer reserve.
5. Never the reserve floor.

## 5. Log

A minimal ledger is enough:

| Date | Event | Action | Cost | Points | Reward | Note |
| --- | --- | --- | --- | --- | --- | --- |
| 2026-10-20 | AvA + SB | 12h build finish | 2× 1h | ? | Tier 3 | Landed in overlap |

After four weeks, you will know which actions are worth repeating and which are theatre.

## The portfolio mindset

Rank events by **value per resource**, not by excitement:

- **Alliance rank events** usually justify the biggest spend.
- **Personal ladders** are good for guaranteed milestones.
- **Limited-time shops** are worth it only if the primary reward is reachable.
- **Cosmetic or low-tier rewards** should not touch the reserve.

If an event does not fit the portfolio this week, skip it deliberately. Skipping is a strategy, not a failure.
