<Callout type="strategy" title="Doctrine beats improvisation">
An advanced alliance is not one that always has the biggest stockpile. It is one that knows where to spend, who decides, and when to stop. Write it down, run it, review it.
</Callout>

## The decision system

For each event week, define:

1. **Objective:** rank target, milestone floor, or development week.
2. **Phase allocation:** percentage of stockpile per phase.
3. **Stop conditions:** score threshold, reserve floor, time limit.
4. **Authority:** who can change the allocation mid-event.
5. **Review time:** when the data will be examined.

If any of the five is missing, the plan will drift.

## Opponent analysis

Track the opposing alliance across weeks:

| Signal | What it tells you |
| --- | --- |
| Fast phase start | They front-load; hold a counter-push |
| Late spike | They save for the final hour; pressure earlier |
| Weak phase | Allocate stockpile to exploit it |
| Overcommitment | Let them spend, then win a later phase |
| Member concentration | Target coordination, not raw score |

<Callout type="warning" title="Do not overfit">
One result is an anecdote. Three or more weeks is a pattern. Keep the dated evidence.
</Callout>

## Allocating scarce stockpiles

Use expected value:

> **Expected points = action points × probability the phase is contested × strategic multiplier**

The strategic multiplier accounts for:

- Daily phase win value.
- Total score pressure.
- Member morale.
- Future stockpile needs.

You will never have perfect numbers. A rough, written ranking beats an intuitive equal split.

## The final hour

The last 60 minutes is a separate sub-game:

- The closer has authority to release the reserve.
- Everyone else stops spending unless called.
- Score updates every 10 minutes.
- Screenshots are taken before reset.
- The after-action note is written the next day, not in the heat of the moment.

## Doctrine library

Keep a small set of repeatable plays:

- **Early pressure** — score fast, force a response, hold reserve.
- **Silent bank** — low early spend, large final-hour push.
- **Phase sacrifice** — concede a phase, win two others efficiently.
- **Coverage play** — flood a neglected phase with mid-power members.
- **Defensive week** — protect rank, rebuild stockpile, skip optional spends.

Each play has prerequisites and risks. Write them down so a new captain can run them without reinventing the plan.
